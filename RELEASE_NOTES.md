Pi Desktop runs [Pi](https://github.com/earendil-works/pi) sessions on this Mac and on SSH hosts side by side, with any model from any provider.

**Install:** download the `.dmg` for your Mac (`arm64` = Apple Silicon, `x64` = Intel), drag Pi Desktop to Applications, then right-click → Open the first time (the app is ad-hoc signed, not notarized). Later versions install themselves: an **Update** button appears next to Settings.

**In this release**
- A reply's work folds into one line, like Claude: reasoning, commands and the notes Pi wrote between them collapse to "Ran 2 commands, read 1 file"; expand it to see each step. The answer stays visible.
- No more generic "exec" icons in the Dock while Pi works: Pi now runs on the app's helper, which stays out of the Dock.
- Settings → Usage: total and daily tokens, a year of token activity, and models ranked by tokens.
- Numbered and bulleted lists continue in the message box: Shift+Enter on "1. …" starts "2. ", and an empty item ends the list.
- Long commands no longer make the conversation scroll sideways; rows truncate and the expanded command wraps.
- Buttons and rows keep the arrow pointer and highlight on hover, as in Claude and Codex.
