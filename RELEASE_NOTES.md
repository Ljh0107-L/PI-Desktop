Pi Desktop runs [Pi](https://github.com/earendil-works/pi) sessions on this Mac and on SSH hosts side by side, with any model from any provider.

**Install:** download the `.dmg` for your Mac (`arm64` = Apple Silicon, `x64` = Intel), drag Pi Desktop to Applications, then right-click → Open the first time (the app is ad-hoc signed, not notarized). Later versions install themselves: an **Update** button appears next to Settings.

**In this release**
- Attach images and files: paste, drag and drop, or the paperclip. Files reach SSH hosts automatically.
- `/` commands in the message box, including Codex-style `/goal` that keeps Pi working until the goal is achieved.
- Edit a message you sent and regenerate from there; fork a conversation; right-click a conversation for Rename / Fork / Archive / Delete.
- Change review: each reply lists the files it changed, with diffs.
- Terminal panel (⌃\`) in the session's folder, on this Mac or the SSH host.
- Conversations on this Mac keep running after you quit the app, like SSH ones.
- 1-hour prompt caching by default; usage panel with speed, input, cached and output tokens.
